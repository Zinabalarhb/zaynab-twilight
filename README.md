# Overview

**Zaynab** is a premium custom theme built for the **Salla Twilight Engine**.

The theme focuses on creating a luxurious shopping experience for fashion and abaya stores using a modern interface with elegant typography, rich colors, and reusable Twig components.

Main design palette:

- Navy
- Gold
- Burgundy
- Silk Beige

The theme is fully RTL compatible and optimized for Arabic eCommerce stores.

# Installation

Clone the repository

```bash
git clone https://github.com/Zinabalarhb/zaynab-twilight.git
```

Install Salla CLI

```bash
npm install -g @salla.sa/cli
```

Run Preview

```bash
salla theme preview
```

or

```bash
salla theme p
```

---

# Development

After making changes, simply run:

```bash
salla theme preview
```

The preview server will automatically reload your theme.
